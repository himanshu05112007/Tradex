# TradeX — Stock Trading Platform

TradeX is a modern, responsive frontend stock trading platform designed to simulate the experience of an online trading terminal.

## Overview

TradeX provides an interactive interface for exploring stock market information and experiencing simulated paper trading without using real money.

## Features

- Modern, responsive user interface
- Stock market dashboard
- Stock watchlist
- Simulated buy and sell orders
- Market and limit order interface
- Portfolio and holdings overview
- Simulated balance and transaction history
- Order notifications
- Local storage for persisting simulated trading data

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Browser Local Storage

## Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

Clone the repository:

    git clone https://github.com/himanshu05112007/Tradex.git

Open the project folder:

    cd Tradex

Install the dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.
